# edanliahovetsky.github.io

Personal site for Edan Liahovetsky: robotics software, BLine, research, and leadership.

A static site with no build step. To preview it locally:

```bash
python3 scripts/serve.py 8001
```

Then open http://localhost:8001. (`scripts/serve.py` supports Range requests, which the scroll-scrubbed videos need.)
